ONLYOFFICE plugin mock harness

Runs the real bridge.js, insert.js and plugin.js against a fake Asc.plugin. The editor itself is a normal build, so the checks cover the whole export → OLE object → reopen flow. Serve this folder over HTTP (for example python3 -m http.server inside onlyoffice-plugin); file:// blocks the iframe's modules.

Needs onlyoffice-plugin/web/: run ./build.sh, or point the editor URL at a dev server such as http://localhost:5173/?embed.
